# Privacy Policy

Last updated: September 4, 2026

Dealer Inspire WordPress Admin Login does not collect, store, transmit, share, or sell user data.

The extension uses the currently active tab only after the user clicks its toolbar icon. It changes that tab's URL to the site's `/wp/wp-admin/` path. The extension does not access WordPress credentials, does not use analytics, and does not make network requests.

For privacy questions, contact the extension publisher through the support contact listed in the Chrome Web Store.
